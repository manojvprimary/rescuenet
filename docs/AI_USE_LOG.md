# AI-Use Log

This log records how AI assistance (Claude / Claude Code) was used across the RescueNet capstone sequence (ISEM 502 → GRAD 695 → GRAD 699), per GRAD 699's AI-use disclosure requirement.

## How AI was used

- **Code and infrastructure (ISEM 502 – GRAD 695):** Claude Code was used as a pair-programming tool for the CDK stacks, Lambda functions, GraphQL schema, and the Expo mobile app — scaffolding, implementation, debugging, and iteration were AI-assisted throughout, with architectural decisions (blackboard pattern, event catalog, agent responsibilities, data model) directed and reviewed by the student.
- **Documentation (GRAD 695):** The Applied Project Report, its figures, and the repository README were drafted by Claude Code from the student's direction and the project's actual architecture/code, then reviewed and revised by the student. The report's literature review used real, independently verified citations (checked against live search results where less common) rather than AI-recalled references alone.
- **UX Portfolio (ISEM 502):** Personas, heuristic evaluation, and prototype descriptions were AI-drafted from the student's own research notes and design direction.
- **Case study (separate UCD course):** A redesign case study reused the student's own previously authored first-person usability account as primary data; AI was not used to generate or simulate user research data.
- **GRAD 699 (ongoing):** Claude Code is being used for planning artifacts (pitch, project snapshot, this log), repository setup, and will continue to assist with implementation of the shelter onboarding portal extension, under the same student-directed, student-reviewed model.

## What AI was *not* used for

- No AI-generated or fabricated user research data (survey responses, interview transcripts, or usability-test results) has been presented as real at any point. Where a course step assumed team-based data collection that wasn't available, the constraint was disclosed rather than simulated (see GRAD 695 Section 2.6/4.2 methodology notes).
- No AI-invented citations; all literature references are real, published works.

## Tools

- Claude Code (Anthropic), via the Claude Sonnet 5 model, used interactively across all phases above.
